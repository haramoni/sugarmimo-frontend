# Dados de localidades brasileiras

`brazil-locations.json` contém nomes, códigos e coordenadas centrais de estados e municípios brasileiros. O arquivo foi reduzido aos campos usados pelo filtro de busca a partir do projeto [kelvins/municipios-brasileiros](https://github.com/kelvins/municipios-brasileiros), distribuído sob licença MIT. Os códigos de localidade seguem o IBGE.
